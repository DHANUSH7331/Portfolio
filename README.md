# Siriki Sai Dhanush — Developer Portfolio

Personal portfolio of a Junior Developer working across Python/Django, web development, data analytics and AI-assisted automation.

**Live site:** https://portfolio-kohl-gamma-18.vercel.app

## What's inside

- **Experience** — current role and training focus (WordPress, Landbot.io, Claude Skills, MCP connections, webhooks, API integrations)
- **Skills** — backend, frontend, data analytics, Power BI, Python for data, machine learning, databases and tools
- **Education** — MCA (Andhra University College of Engineering) and B.Sc. (Mrs. A.V.N. College)
- **Projects** — Vesper personal finance dashboard (PWA), drone detection with YOLOv8 + ESRGAN, loan approval prediction, urban energy smart grid dashboard (Power BI), Django bank management system, products web app
- **Contact** — message form (EmailJS) plus a Landbot live-chat widget

## Tech

Plain HTML5, CSS3 and vanilla JavaScript. No build step and no framework.

| Piece | File |
| --- | --- |
| Markup | `index.html` |
| Styles | `new.css` |
| Behaviour (typing effect, scroll reveals, contact form) | `new.js` |
| Images and icons | `Images/` |
| SEO and sharing | `favicon.svg`, `apple-touch-icon.png`, `og-image.png`, `robots.txt`, `sitemap.xml` |

## Run locally

```bash
git clone https://github.com/DHANUSH7331/Portfolio.git
cd Portfolio
python -m http.server 8000
# open http://localhost:8000
```

## Deployment

Deployed on Vercel from the `main` branch; every push to `main` triggers a production deploy.
